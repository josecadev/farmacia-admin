# Sistema de Administración de Farmacia

Proyecto para mejorar la administración de una farmacia mediante un sistema moderno y eficiente.

##  Inicio Rápido

### Requisitos Previos

- Node.js (v18 o superior) o Python 3.8+
- Git
- Navegador web moderno

### Instalación Local

1. Clonar el repositorio:
```bash
git clone https://github.com/tu-usuario/farmacia-admin.git
cd farmacia-admin
```

2. Ejecutar el script de configuración:
```bash
# Windows
.\setup.bat

# Linux/Mac
chmod +x setup.sh
./setup.sh
```

3. Verificar la instalación:
```bash
# Para Node.js
npm start

# Para Python
python src/app.py
```

4. Abrir en el navegador: `http://localhost:3000` (o el puerto que se indique)

##  Flujo de Trabajo (Gitflow)

Este proyecto utiliza Gitflow para la gestión de ramas. Consulta [CONTRIBUTING.md](CONTRIBUTING.md) para más detalles.

### Ramas Principales

- `main`: Código en producción
- `develop`: Código en desarrollo
- `feature/*`: Nuevas funcionalidades
- `bugfix/*`: Corrección de bugs
- `hotfix/*`: Correcciones urgentes
